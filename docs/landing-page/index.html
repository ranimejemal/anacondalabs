Process

Three steps, no infrastructure to stand up

Runs entirely on your own machine. Nothing about your API or your code is sent anywhere unless you explicitly turn on AI-powered fixes.

01 — TARGET

Point it at your API

Import an OpenAPI/Swagger spec, add endpoints manually, or upload a source code .zip for a static scan with no running API needed at all.

02 — CONFIRM

Confirm authorization

A required consent checkbox before any live scan runs — AegisLab is built for testing systems you own or are explicitly authorized to test, full stop.

03 — REVIEW

Get a scored, explained report

A 0–100 security score, every finding mapped to its OWASP category with plain-language impact and fix guidance, exportable as JSON or PDF.

Coverage

7 of 10 OWASP API Security Top 10 categories

The three not covered — sensitive business flow abuse, inventory management, and third-party API trust — are structural problems that don't reduce to a single automated HTTP probe. We'd rather say so than fake coverage.
